# iPhone 快捷指令记账

不用打开微信，在锁屏、控制中心、操作按钮或 Siri 上直接记一笔。快捷指令记的账和微信里记的账归到**同一个家庭成员**名下，家里每个人都可以各自配置。

整个配置只在手机上点选，不需要写代码。

## 一、先在网页后台拿到密钥

1. **确认成员已经存在**
   - 家人如果用过微信记账，系统已经自动建好了这个成员（名字类似「微信用户_ab12」，可以在「成员管理」里改成好认的名字）。
   - 还没用过微信的，先给微信机器人发一句「午饭 35」，或者直接在「成员管理」里新建。
   - 想让快捷指令和微信记到同一个人身上，就要在**微信对应的那一行**生成密钥。
2. 打开后台「成员管理」，在这个人那一行点 🔑 钥匙图标。
3. 填一个设备名（比如「老婆的 iPhone」），点「生成密钥」。
4. 弹出的黄色框里有两样东西，分别复制下来：
   - **接口地址**：形如 `https://<你的域名>/api/v1/quick/record`
   - **密钥**：以 `cw_` 开头的一长串

> 密钥只显示这一次。没记下来也没关系，作废后重新生成一把就行。每台设备建议单独一把，手机丢了只作废那一把，不影响其他人。

## 二、快捷指令「记一笔」（打字或说话）

在 iPhone 上打开「快捷指令」App，点右上角 **＋** 新建，把名字改成「记一笔」，然后依次添加下面几个操作。

1. **要求输入**
   - 输入类型：文本
   - 提示：`记一笔，比如：午饭 35`
   - 弹出输入框时可以直接打字，也可以点键盘上的麦克风说话。
2. **获取 URL 内容**
   - URL：粘贴第一步复制的**接口地址**
   - 点「显示更多」，然后设置：
     - 方法：`POST`
     - 头部：添加一项，键填 `Authorization`，值填 `Bearer `（Bearer 后面有一个空格）再粘贴**密钥**
     - 请求体：`JSON`，添加一个「文本」字段，键填 `text`，值选上一步的变量「提供的输入」
3. **显示通知**
   - 内容选变量「URL 的内容」

运行一次试试：输入「午饭 35」，几秒后会弹出通知「已记录：餐饮 支出 35.00 元 … · 某某」。末尾的名字就是这笔账记到了谁名下。

第一次运行时 iPhone 会问是否允许连接这个域名，选「始终允许」。

## 三、快捷指令「记账截图」（支付截图 / 小票照片）

1. 新建快捷指令，命名「记账截图」。
2. 点底部的 ⓘ（详细信息），打开「在共享表单中显示」，接收类型只勾「图像」。
   - 编辑页顶部会出现「接收 图像 输入，来自 共享表单」。
   - 把「如果没有输入」设为「请求 照片」，这样从桌面点开时会让你选一张图。
3. 依次添加：
   1. **转换图像**：把「快捷指令输入」转换为 `JPEG`。iPhone 拍的照片默认是 HEIC，系统识别不了，这一步不能省。
   2. **调整图像大小**（可选，但推荐）：宽度 `1500`，高度自动。图片小一些，上传和识别都更快。
   3. **获取 URL 内容**：
      - URL 和头部与「记一笔」完全一样。
      - 请求体改选 `文件`，文件选上一步的图像。
   4. **显示通知**：内容选「URL 的内容」。

用法：在相册或截图预览里点「分享」，选择「记账截图」，几秒后弹出识别结果。

## 四、快捷指令「截屏记账」（截屏后自动识别，确认才记）

iPhone 的自动化里**没有「截屏时」这个触发条件**，没法在你按电源键截屏时自动运行。变通办法是让快捷指令**自己截屏**：在付款成功的页面轻点手机背面三下，它会截下当前屏幕交给 AI 识别。

- 是账单：弹出菜单「支出 35.00 元 · 餐饮 · 午饭」，你选「记这笔」才入账。
- 不是账单：什么也不弹，安静结束。
- 识别出来的结果先放在服务器上等你确认，15 分钟内不确认就自动作废，不会记进账本。

新建快捷指令，命名「截屏记账」，依次添加：

1. **截屏**
2. **存储到相簿**（可选）：想同时留一张普通截图就加上；不想付款截图塞满相册就不加。
3. **转换图像**：把「截屏」转换为 `JPEG`。
4. **调整图像大小**：宽度 `1500`，高度自动。
5. **获取 URL 内容**
   - URL：把接口地址末尾的 `/record` 改成 **`/preview`**
   - 方法 `POST`，头部 `Authorization` 和「记一笔」一样
   - 请求体选 `文件`，文件选上一步调整后的图像
6. **获取词典值**：获取「`status`」的值，词典选「URL 的内容」。
7. **如果**「词典值」**是** `found`：
   1. 再加三个 **获取词典值**，词典都选第 5 步的「URL 的内容」，分别取 `summary`、`draftId`、`text`。
   2. **从菜单中选取**：提示选变量 `summary`，选项写三个：`记这笔`、`改一下再记`、`不记`。
      - **记这笔**：
        - 添加 **获取 URL 内容**：URL 把末尾改成 **`/confirm`**；方法 `POST`，头部同上；请求体 `JSON`，加一个文本字段，键 `draftId`，值选变量 `draftId`。
        - 再添加 **显示通知**，内容选「URL 的内容」。
      - **改一下再记**：
        - 添加 **要求输入**：类型文本，默认答案选变量 `text`。识别有偏差时，在这里改金额或描述。
        - 再添加 **获取 URL 内容**：和「记一笔」完全一样，URL 用 `/record`，JSON 字段 `text` 选「提供的输入」。
        - 最后添加 **显示通知**。
      - **不记**：什么都不放。
8. 在「如果」的 **否则** 里，嵌套一个 **如果**：第 6 步的「词典值」是 `error` 时，**获取词典值** `message`，再 **显示通知**。
   - 这样密钥填错、图片格式不对之类的问题会提示你。
   - 「不是账单」的情况仍然安静结束。

**触发方式**：设置 → 辅助功能 → 触控 → 轻点背面 → 轻点三下 → 选「截屏记账」。「轻点两下」可以继续留给「记一笔」。iPhone 15 Pro 及之后的机型也可以绑在操作按钮上。

> 平时普通截屏照常按电源键加音量键，不受影响。只有想记账时才轻点背面。
> 第一次运行时，iPhone 会请求截屏和联网权限，都选「始终允许」。

## 五、快捷指令「截屏直接记」（简化版，不确认）

不想每次多点一下「记这笔」的话，可以用这个简化版：截屏后直接交给 AI。认出是账单就记进去；认不出（不是账单、读不出金额）就**不入库**。

新建快捷指令，命名「截屏直接记」，依次添加 5 个操作：

1. **截屏**
2. **转换图像**：把「截屏」转换为 `JPEG`。
3. **调整图像大小**：宽度 `1500`，高度自动。
4. **获取 URL 内容**
   - URL 用原来的 **`/record`** 地址，和「记一笔」一样，不用改。
   - 方法 `POST`，头部 `Authorization` 和「记一笔」一样。
   - 请求体选 `文件`，文件选上一步调整后的图像。
5. **显示通知**：内容选「URL 的内容」。

结果分三种：

- 记上了：通知「已记录：餐饮 支出 35.00 元 … · 某某」。
- 不是账单：通知「没在图片里识别到消费信息…」，不会入库。
- 密钥错、图片格式不对：通知对应的错误提示，见下面「常见提示」。

**不想看到"没识别到"的通知**：在第 5 步外面套一层 **如果**，条件为「URL 的内容」**包含** `已记录`，「显示通知」放进去。这样只有真的记上了才弹，其余情况安静结束。不过密钥填错这类问题也会被一起藏起来，建议先跑通几次再加。

**和「截屏记账」怎么选**：

| | 截屏直接记（本节） | 截屏记账（第四节） |
|---|---|---|
| 操作 | 轻点背面三下就完事 | 轻点三下，再点一次「记这笔」 |
| 不是账单时 | 弹「没识别到」（可以关掉），不入库 | 安静结束 |
| AI 认错时 | 错的那笔已经入账，需要到网页「记账」里改或删 | 弹窗里就能看到，可以「改一下再记」或「不记」 |
| 配置 | 5 步 | 十来步，带判断和菜单 |

> 最容易认错的是「看着像账单」的页面，比如商品详情、购物车里的价格。只在**付款成功页**上轻点，基本不会误记。
> 「轻点背面三下」只能绑一个快捷指令，两个版本二选一；另一个可以绑到操作按钮，或者从控制中心点。

## 六、放到顺手的位置

| 入口 | 怎么设置 | 适合 |
|---|---|---|
| 锁屏按钮（iOS 18+） | 长按锁屏 → 自定 → 锁定屏幕 → 点底部左/右按钮的「－」移除，再点「＋」→ 快捷指令 → 选「记一笔」 | 亮屏就能点 |
| 控制中心（iOS 18+） | 下拉控制中心 → 左上角「＋」→ 添加控制 → 快捷指令 → 选「记一笔」 | 任何界面下拉即用 |
| 操作按钮（iPhone 15 Pro 及之后） | 设置 → 操作按钮 → 滑到「快捷指令」→ 选「记一笔」 | 按一下侧键就记 |
| 轻点背面 | 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「记一笔」 | 单手操作 |
| Siri | 直接说「嘿 Siri，记一笔」，Siri 会语音问你内容 | 开车、做饭时 |
| 主屏幕 | 在快捷指令上长按 → 共享 → 添加到主屏幕 | 当作一个 App 图标 |

从锁屏触发时，iPhone 可能要先面容解锁才能联网，这是系统的安全限制。

## 七、多人使用

- 每个家人在自己的 iPhone 上按上面步骤做一遍，用**自己那一行**生成的密钥。
- 记账页的「来源」一栏会显示「快捷指令」或「快捷指令截图」，和微信录入的账目区分开，但归属的成员相同。
- 「消息日志」里能看到每次快捷指令的原始内容和处理结果。
- 生成密钥的窗口里能看到每把密钥的「最近使用」时间。不用的设备点 🗑 作废即可。

## 八、常见提示

| 通知内容 | 原因和处理 |
|---|---|
| 密钥无效或已作废… | 密钥填错、少了 `Bearer `，或者已被作废。重新生成一把再填。 |
| 没有收到内容… | 请求体没设置好，检查 `text` 字段有没有选「提供的输入」。 |
| 暂不支持 HEIC 格式… | 「记账截图」里漏了「转换图像 → JPEG」这一步。 |
| 图片太大了… | 加上「调整图像大小」。 |
| 记得太快了… | 同一把密钥每分钟最多记 20 笔，稍等一分钟。 |
| 这笔已经记过了，或者确认超时… | 「截屏记账」弹窗后超过 15 分钟才点确认，或者同一笔点了两次。重新截一次即可。 |
| 没在图片里识别到消费信息… | 截图里没有付款金额，或者不是账单页面，这次没有入账。换付款成功页再截一次。 |
| 没有「已记录」，只有一句 AI 的回复 | AI 没从这句话里读出金额，换个说法，比如「打车 22」。 |
