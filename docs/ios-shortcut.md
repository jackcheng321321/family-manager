# iPhone 快捷指令记账

不用打开微信，在锁屏、控制中心、操作按钮或 Siri 上直接记一笔。快捷指令记的账和微信里记的账归到**同一个家庭成员**名下，家里每个人都可以各自配置。

整个配置只在手机上点选，不需要写代码。

## 一、先在网页后台拿到密钥

1. **确认成员已经存在**
   - 家人如果用过微信记账，系统已经自动建好了这个成员（名字类似「微信用户_ab12」，可以在「成员管理」里改成好认的名字）。
   - 还没用过微信的，先给微信机器人发一句「午饭 35」，或者直接在「成员管理」里新建。
   - 想让快捷指令和微信记到同一个人身上，就要在**微信对应的那一行**生成密钥。
2. 打开后台「成员管理」，在这个人那一行点 🔑 钥匙图标。
3. 填一个设备名（比如「老婆的 iPhone」），点「生成密钥」。
4. 弹出的黄色框里有两样东西，分别复制下来：
   - **接口地址**：形如 `https://<你的域名>/api/v1/quick/record`
   - **密钥**：以 `cw_` 开头的一长串

> 密钥只显示这一次。没记下来也没关系，作废后重新生成一把就行。每台设备建议单独一把，手机丢了只作废那一把，不影响其他人。

## 二、快捷指令「记一笔」（打字或说话）

在 iPhone 上打开「快捷指令」App，点右上角 **＋** 新建，把名字改成「记一笔」，然后依次添加下面几个操作。

1. **要求输入**
   - 输入类型：文本
   - 提示：`记一笔，比如：午饭 35`
   - 弹出输入框时可以直接打字，也可以点键盘上的麦克风说话。
2. **获取 URL 内容**
   - URL：粘贴第一步复制的**接口地址**
   - 点「显示更多」，然后设置：
     - 方法：`POST`
     - 头部：添加一项，键填 `Authorization`，值填 `Bearer `（Bearer 后面有一个空格）再粘贴**密钥**
     - 请求体：`JSON`，添加一个「文本」字段，键填 `text`，值选上一步的变量「提供的输入」
3. **显示通知**
   - 内容选变量「URL 的内容」

运行一次试试：输入「午饭 35」，几秒后会弹出通知「已记录：餐饮 支出 35.00 元 … · 某某」。末尾的名字就是这笔账记到了谁名下。

第一次运行时 iPhone 会问是否允许连接这个域名，选「始终允许」。

## 三、快捷指令「记账截图」（支付截图 / 小票照片）

1. 新建快捷指令，命名「记账截图」。
2. 点底部的 ⓘ（详细信息），打开「在共享表单中显示」，接收类型只勾「图像」。
   - 编辑页顶部会出现「接收 图像 输入，来自 共享表单」。
   - 把「如果没有输入」设为「请求 照片」，这样从桌面点开时会让你选一张图。
3. 依次添加：
   1. **转换图像**：把「快捷指令输入」转换为 `JPEG`。iPhone 拍的照片默认是 HEIC，系统识别不了，这一步不能省。
   2. **调整图像大小**（可选，但推荐）：宽度 `1500`，高度自动。图片小一些，上传和识别都更快。
   3. **获取 URL 内容**：
      - URL 和头部与「记一笔」完全一样。
      - 请求体改选 `文件`，文件选上一步的图像。
   4. **显示通知**：内容选「URL 的内容」。

用法：在相册或截图预览里点「分享」，选择「记账截图」，几秒后弹出识别结果。

## 四、放到顺手的位置

| 入口 | 怎么设置 | 适合 |
|---|---|---|
| 锁屏按钮（iOS 18+） | 长按锁屏 → 自定 → 锁定屏幕 → 点底部左/右按钮的「－」移除，再点「＋」→ 快捷指令 → 选「记一笔」 | 亮屏就能点 |
| 控制中心（iOS 18+） | 下拉控制中心 → 左上角「＋」→ 添加控制 → 快捷指令 → 选「记一笔」 | 任何界面下拉即用 |
| 操作按钮（iPhone 15 Pro 及之后） | 设置 → 操作按钮 → 滑到「快捷指令」→ 选「记一笔」 | 按一下侧键就记 |
| 轻点背面 | 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「记一笔」 | 单手操作 |
| Siri | 直接说「嘿 Siri，记一笔」，Siri 会语音问你内容 | 开车、做饭时 |
| 主屏幕 | 在快捷指令上长按 → 共享 → 添加到主屏幕 | 当作一个 App 图标 |

从锁屏触发时，iPhone 可能要先面容解锁才能联网，这是系统的安全限制。

## 五、多人使用

- 每个家人在自己的 iPhone 上按上面步骤做一遍，用**自己那一行**生成的密钥。
- 记账页的「来源」一栏会显示「快捷指令」或「快捷指令截图」，和微信录入的账目区分开，但归属的成员相同。
- 「消息日志」里能看到每次快捷指令的原始内容和处理结果。
- 生成密钥的窗口里能看到每把密钥的「最近使用」时间。不用的设备点 🗑 作废即可。

## 六、常见提示

| 通知内容 | 原因和处理 |
|---|---|
| 密钥无效或已作废… | 密钥填错、少了 `Bearer `，或者已被作废。重新生成一把再填。 |
| 没有收到内容… | 请求体没设置好，检查 `text` 字段有没有选「提供的输入」。 |
| 暂不支持 HEIC 格式… | 「记账截图」里漏了「转换图像 → JPEG」这一步。 |
| 图片太大了… | 加上「调整图像大小」。 |
| 记得太快了… | 同一把密钥每分钟最多记 20 笔，稍等一分钟。 |
| 没有「已记录」，只有一句 AI 的回复 | AI 没从这句话里读出金额，换个说法，比如「打车 22」。 |
